/goal
Your goal is to continue working on the TrackMania Nations Forever physics decompilation project.
The goal is to have a standalone C++ TrackMania nations forever (TMNF) physics library that has a 100% parity with the original game.
The current project is in the directory called "manual", there are a lot of temporary scripts there too that you can remove if wanted.
The original game installation is in the directory called "steamdata"
The original dump of the functions generated by ghidra is in "scripts/dump.cpp", its about 2 million lines of code. It was split up by the scripts in the scripts directory into different files related to the physics (some might be missing and need to be fetched from dump.cpp directly if necessary or not found in the tmnf_dump directory) into the tmnf_dump directory.
There are also other libraries present here to analyze the files and have additional context of the structures used in the game so we can base some assumptions we have about the code on previous work from other developers (gbx_map, gbx-io, gbx-tools-3d, GbxDump)
The "exe" directory contains the original .exe and .pdb file that was used to dump the functions. You can analyze it more if necessary.
"manual/test_compile.sh" tries to compile all the sources and a test harness that runs the simulation, it is not correctly working right now as you can see based on the data, we are using ghost data to validate our physics and see how different they are. I think the whole collision system is still unfinished.
Find what needs working on to arrive at the 100% parity, it is okay to get there in steps.
Some Static data that i couldn't get from ghidra directly (or at least i didn't know how) is still missing, many of those are important physics constants, if you can retrieve them accurately, please do so.
